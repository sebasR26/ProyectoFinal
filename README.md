# ProyectoFinal

## HU3: Creación de las clases de equipos electrónicos
Yo como Product Owner
requiero que se creen las clases ComputadorPortatil y TabletaGrafica
para representar los equipos electrónicos disponibles para préstamo a los estudiantes.
Criterios de aceptación:
La clase TabletaGrafica incluye:
Serial (String)
Marca (String)
Tamaño (float, en pulgadas)
Precio (float)
Método con submenú para almacenamiento:
256 GB
512 GB
1 TB
Peso (float, en kg)
La clase ComputadorPortatil incluye:
Serial (String)
Marca (String)
Tamaño (float, en pulgadas)
Precio (float)
Submenú para Sistema Operativo:
Windows 7
Windows 10
Windows 11
Submenú para Procesador:
AMD Ryzen
Intel Core i5
Los datos se validan correctamente según su tipo.
No se permiten caracteres especiales ni números en campos de texto (marca, serial, etc.).
